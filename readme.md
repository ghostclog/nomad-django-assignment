# 노마드 코드 파이썬 챌린지 / 에어비엔비(Django) 졸업 작품입니다.

# 프로젝트 구조
기본적으로 트위터(현 X)를 Rest API로 클론 코딩을 하는거 같아서, 제시된 과제 목표 위에 트위터 사이트를 최대한 참고하여 설계하였습니다.

- users app(사용자 앱): 트위터와 최대한 유사한 사용자 정보를 저장 및 처리해주는 앱입니다. 유저 생성/삭제/수정. 로그인, 로그아웃, 비밀번호 수정과 같은 기능들이 구현되어 있습니다.

- tweets app(트윗 앱): 트위터의 트윗 기능과 최대한 유사하게 구현해두었습니다. 트윗 작성, 삭제, 수정. 좋아요 기능이 구현되어있으나, 북마크나 리트윗 기능은 구현되어 있지 않습니다.
